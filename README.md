# iOS 26 Simulator (Web)

ตัวจำลองหน้าตา iOS 26 แบบพื้นฐาน เขียนด้วย HTML/CSS/JS ล้วน ไม่ต้อง build

## ฟีเจอร์
- **Liquid Glass** — แผงกระจกเบลอ (`backdrop-filter`) พร้อมขอบสะท้อนแสง ใช้กับ Dock, Control Center, แถบ Chrome, การแจ้งเตือน
- **พื้นหลังเคลื่อนไหว** — gradient blob ลอยช้าๆ เลือกได้ 4 แบบใน Settings
- **อนิเมชั่น** — ปลดล็อกแบบปัดขึ้น, แอปซูมออกจากไอคอนและกลับเข้าไอคอนตอนปิด, Dynamic Island ขยายตัว
- **Chrome ใช้งานได้จริง** — พิมพ์ URL หรือคำค้น (ค้นผ่าน Bing), ปุ่มย้อน/ไปหน้า/รีโหลด/เปิดในแท็บใหม่
  - เว็บที่ห้ามฝังใน iframe (Google, YouTube, Facebook ฯลฯ) จะขึ้นปุ่ม "เปิดในแท็บใหม่" แทน
- แอปอื่น: Settings (วอลเปเปอร์, Dark Mode), Calculator, Clock (นาฬิกาจับเวลา), Control Center (ปรับความสว่างได้)

## วิธีรัน
```sh
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```
หรือเปิด `index.html` ตรงๆ ในเบราว์เซอร์ก็ได้

## การควบคุม
- คลิก/ปัดขึ้นที่หน้าล็อก → ปลดล็อก
- คลิก/ปัดขึ้นที่แถบล่าง หรือกด `Esc` → กลับหน้าโฮม
- คลิกไอคอนสัญญาณมุมขวาบน → Control Center
